# ポートフォリオ企画メモ

README の「僕という人間がすべて詰まったポートフォリオ」を、訪れた人が体験できる形にする。今の出発点は「人と話すのが好き」。

## 仮案「少し、話していきませんか？」

訪問者の選んだ話題から、本人のエピソードと作品にたどり着く。たとえば、相手の一言を掘るのが好きなら、選んだ言葉を次の質問で拾う。考えを交換するのが好きなら、訪問者が自分の答えを選んだあとで、本人の答えと理由が読めるようにする。

1. 本人が普段の言葉で問いかける。
2. 選んだ答えに応じて、本人の短いエピソードや次の問いが出る。
3. 話につながる作品が開き、何を作ってどう判断したかが読める。
4. 作品一覧にも最初の画面から直接行ける。

## 自分の言葉を集める

最近楽しかった会話を一場面だけ思い出す。相手が何と言って、自分はどう返して、そのやりとりの何が楽しかったか。会話で考えが変わった経験や、つい熱が入る話題も、作品につながるなら使う。

問いと返事の初稿は、本人が普段の言葉で書くか、話した内容を起こす。AIはそこから導線と試作品を組む。採用する言葉と、どの体験が自分らしいかの判断は本人が持つ。

## 最初の試作

問い一つ、選択肢二つ、短い返事、作品一つで作る。友人一人に説明なしで触ってもらい、「どんな人だと思った？」「どの言葉でそう思った？」と聞く。伝えたかった印象と照らし合わせ、問いと返事を直す。画面の演出や技術は、会話の流れを試してから決める。
